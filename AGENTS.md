# Repository guide

This public repository is the account-wide source of default GitHub community health files for XIYO.

## Rules

- Keep guidance generic enough to apply to every public XIYO repository.
- Put project-specific commands, platforms, support windows, and architecture rules in the affected repository.
- Do not add labels to inherited issue forms unless those labels exist in every consuming repository.
- Never request or expose credentials, personal source content, production data, local database files, or stable account identifiers.
- Security reports must use private vulnerability reporting or the contact in `SECURITY.md`, never a public issue.
- A repository-specific file overrides the corresponding default. Avoid copying defaults into individual repositories unless an override is necessary.
