# XIYO community health files

This repository provides the default contribution, support, security, and issue-reporting guidance for XIYO's public repositories.

GitHub applies these files to repositories that do not define a project-specific version. Individual projects may override a default when their workflow or security boundary requires more detail.

## Defaults provided

- [Contributing](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Support](SUPPORT.md)
- [Code of Conduct](CODE_OF_CONDUCT.md)
- Bug and feature request forms
- Pull request checklist

Repository-specific installation and verification instructions remain in each project's own README.
