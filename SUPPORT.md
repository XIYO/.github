# Support

## Usage questions and bugs

Open an issue in the repository that contains the affected tool. Include the tool version, host application, operating system, installation method, expected result, actual result, and the smallest reproducible example.

Before submitting diagnostics, remove credentials, tokens, personal messages, calendar contents, phone numbers, email addresses, local paths, and stable account identifiers.

## Security issues

Follow the [security policy](SECURITY.md). Do not report vulnerabilities in a public issue.

## Scope

Public issue support is best-effort. Project READMEs define supported platforms, maturity, and known limitations; experimental projects may not provide migration or compatibility guarantees.
